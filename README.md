# 校准追溯站（Calibration Traceability Station）

本地 Go Web 服务：管理设备、单位、参考点和**带有效期、带指纹的曲线版本**，导入带
**设备采样时刻**与**接收时刻**的原始读数，输出校准值、不确定度与使用的曲线区段，
并能从任何结果追溯到原始样本、曲线版本指纹与物理参考点。

## 设计要点

- **历史冻结**：校准在导入时一次性完成，结果内嵌选择理由与版本 SHA-256 指纹；
  新版本发布永不改写旧结果。版本对比（what-if）只即时重算，不写回。
- **曲线**：分段线性（端点节点即区间端点）与 1–3 阶多项式（中心化系数）。
  每个区间的两端分别声明开/闭；除“端点相接”外，任何未声明重叠都被拒绝；
  有意的重叠用 `overlap_group` 声明并用 `priority` 消歧。
- **版本选择**：仅考虑“接收时刻之前已发布、且有效期覆盖接收时刻”的版本；
  随后还必须覆盖读数声明的采样时刻。设备时钟回拨（采样时刻落在确认版本窗口之外）
  会被明确标记，而不是静默回退到旧曲线。多版本生效 → 歧义错误。
- **外推**：默认禁止；版本显式 `allow_extrapolate` 时仅允许沿边界线性段外推，
  并按 `extrap_uncertainty_rate × 距离` 附加不确定度（与其他项平方和开根）。
- **单位**：先量纲检查再换算（含 K/°C/°F 仿射温度）。换算只产生派生显示值，
  原始读数的数值与声明单位原样保存，不会被显示单位覆盖。
- **批量导入**：按设备+样本 id 幂等；同 id 不同原始值/单位/采样时刻判冲突，
  其余合法行继续处理并逐行报告。
- **乐观锁**：设备与曲线版本带 `revision`；已发布版本永久不可编辑。
- **持久化**：JSON 原子写入；导出包携带版本与结果指纹，导入前全部重算校验，
  重启 / 导出 / 导入后指纹、不确定度序列化与选择理由保持一致。

## 构建与运行

```bash
go build ./...
go test ./... -count=1
go run ./cmd/server --addr 127.0.0.1:5234
# 首次启动可直接写入演示数据：
go run ./cmd/server --addr 127.0.0.1:5234 --seed
```

打开 http://127.0.0.1:5234 ，页面标题为「校准追溯站」。

参数：`--addr` 监听地址（默认 `127.0.0.1:5234`），`--data` 数据文件
（默认 `data/station.json`，空串为纯内存），`--seed` 库空时写入演示设备
PT-204、两个已发布版本和四类样本（正常、历史冻结、时钟回拨、超范围外推）。

## API 摘要

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET/POST | `/api/units` | 单位列表 / 注册自定义单位 |
| GET/POST/PUT | `/api/devices[/{id}]` | 设备登记、列表、乐观锁编辑 |
| GET/POST | `/api/reference-points` | 参考点 |
| GET/POST/PUT | `/api/versions[/{id}]` | 曲线版本（草稿可改，发布后冻结） |
| POST | `/api/versions/{id}/publish` | 发布（请求体带 `expected_revision`） |
| GET | `/api/versions/{id}/coverage` | 合并覆盖与内部间隙 |
| POST | `/api/readings/import` | 批量幂等导入 + 校准 |
| GET | `/api/readings[/{id}/trace]` | 原始/校准对照、全链路追溯 |
| POST | `/api/compare` | 两版本对历史样本的非破坏性对比 |
| POST | `/api/convert` | 显示单位换算（先量纲检查） |
| GET/POST | `/api/export`、`/api/import` | 指纹校验的快照导出/合并导入 |
| POST | `/api/demo-seed` | 幂等写入演示数据 |
